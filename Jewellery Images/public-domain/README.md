# Public-domain demo photographs

Twelve photographs downloaded from The Metropolitan Museum of Art's Open Access image service on 2026-11-15. Each object's API metadata explicitly reported `isPublicDomain=true`. The Met describes Open Access images as CC0/public-domain reuse: https://www.metmuseum.org/about-the-met/policies-and-documents/open-access

The adjacent `../demo-import.json` records object page, download URL, creator if identified, credit line, title, culture, SHA-256 and stable ERP code per image. These are historical museum references, not NB Jewel stock, contemporary product photographs, or claims of availability. Any ERP weights, metal purity, charges and stock are assumed demonstration inputs.

Original download pixels are retained. The existing cutout script is reused during ERP upload. Technical generation checks do not approve image quality. Three photos show pairs of earrings; manual review may require a single-earring source for a convincing try-on. No new background-removal engine is introduced.

Existing owner-provided catalog images have unresolved source rights and are separately identified in the manifest. Those records remain Draft until reviewed by the owner.
